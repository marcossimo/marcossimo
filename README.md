### I build products that remove friction.

I'm a full-stack developer and product builder focused on turning real operational problems into clear, reliable SaaS experiences.

- 🛠️ Shipping end to end: product thinking, UX, architecture, data, integrations and production.
- ⚡ Strongest in the TypeScript ecosystem, modern React and data-heavy applications.
- 🤖 Especially interested in AI-assisted workflows, useful automation and tools people can trust.
- 🚀 Currently building **Niverly**, **Afflux** and **ERPSeeker**.
- 📈 Always iterating: ship → observe → improve.
